# CAD Files Repository

This repository serves as a centralized portfolio and archive for my hardware designs, mechanical assemblies, and engineering projects created in Autodesk Fusion 360. 

## 🚀 About This Repository
As an electrical and electronics engineering student with ambitions of building advanced systems and hardware infrastructure, this repository tracks my journey in mechanical design, robotics component creation, and rapid prototyping. 

## 📁 Structure
The repository is organized by projects and specific functional hardware modules:
* **Robotic Arm:** Complete assemblies, structural brackets, gearboxes, and 3D-printable components for robotic manipulation systems.
* **Electronics Enclosures:** Custom mounts and housings for microcontrollers, power supplies, and driver boards (e.g., Arduino, Raspberry Pi, stepper drivers).
* **Mechanical Parts:** Custom-designed gears, planet carriers, shafts, and structural brackets.

## 🛠️ File Formats Used
* **.f3d / Native CAD:** For parametric modeling history and future modifications.
* **.stl / .3mf:** Exported meshes optimized for 3D printing and rapid prototyping.
* **.step:** Universal CAD exchange files for cross-compatibility.
